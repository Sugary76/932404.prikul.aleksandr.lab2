## Описание проекта
Данный проект является продолжением Лабораторной работы №1 и посвящен практическому освоению CSS: работе со стилями, CSS-переменными, позиционированием элементов и настройке состояний элементов.
## Выбранный вариант
Вариант 5. Тема «Геймер и разработчик игр» 
## Использованные технологии
Использовал простые конструкции, выполнил все требования, написанные в методичке, соблюдая критерии задания. Были использованы:
* HTML5
* CSS3
## Реализованные требования:
1. **Способы подключения стилей:**
   * Внешний файл стилей (style.css).
   * Правило во внутреннем блоке style (тег style в index.html для элемента textarea).
   * Элемент с inline стилем (атрибут style="text-transform: uppercase;" на кнопке).

2. **CSS-переменные (:root):**
   * Вынесена палитра цветов (--main-color, --accent-color, --bg-color, --card-bg, --text-color).

3. **Позиционирование элементов:**
   * Относительное позиционирование (position: relative) для карточек проектов (.project-card).
   * Абсолютное позиционирование (position: absolute) для плашки Fav (.badge).

4. **Интерактивные состояния:**
   * :hover и :active — анимация и реакция на курсор для карточек, кнопки и ссылок.
   * :focus — подсветка рамок активных полей ввода (input и textarea).
   * :visited — изменение цвета посещённой ссылки на GitHub в подвале сайта.
